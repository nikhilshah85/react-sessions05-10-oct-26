We need to be good at developing the components
there are 2 ways to do so, 
		components can be developed/designed in 2 ways/mode
	a. function based component - suitable for developers coming from deep JS knowledge
	b. class based component - suitable for developers coming from deep-good OOPS knowledge(java, C#, c++ etc)


	imp - based on the way you develop component, the internal eco system changes during implementation
		eg. state management is handled using key pair values in class based component
			and same is handled using Hooks in function based component

			variable declaration way is also different
